- 2026-09-17 | src/lib/calc/engine.ts | Code fix (not a data change): SME business-flight emissions were computed using the DEFRA LONG-haul per-passenger-km factor (0.11704) even though the tool's own documented default (4,000km round-trip) is explicitly a "regional hub" — i.e. short/medium-haul — assumption. DEFRA's short-haul factor (0.12576) is actually higher per km than long-haul (take-off/landing overhead is a bigger share of a shorter flight), so this was silently understating the SME flights Scope 3 line for every user who filled in a flight count. Fixed to use shortHaulEconomyKgCo2ePerPassengerKm. Found while researching the flight-distance assumption above; MNC mode was already correct (it takes separate short-haul/long-haul passenger-km inputs).
